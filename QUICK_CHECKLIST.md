## Troubleshooting Guide

### NestJS: Cannot find module '@org/proto-contracts'
```bash
# Solution:
npm install
npm cache clean --force
npm install again

# Or verify npm registry auth:
npm set //npm.pkg.github.com/:_authToken=$GITHUB_TOKEN
```

### Spring Boot: Cannot resolve 'com.org:proto-contracts'
```bash
# Solution:
./gradlew clean
./gradlew build --refresh-dependencies

# Verify Maven Central accessibility (proto package should be there)
```

### Proto Compilation Errors
```bash
# Solution:
# Go to central proto repo
cd /Users/smartboy/proto

# Validate locally
buf lint
buf format -w

# Push again
buf push
```

### gRPC Connection Refused
```bash
grpcurl -plaintext localhost:50051 list
```
